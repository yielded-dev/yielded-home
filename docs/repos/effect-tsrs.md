# Effect Diagnostics

This repo implements Effect diagnostics in Rust on top of tsrs and distributes them through the `@yielded/effect-tsrs` CLI and Oxlint integration. Source lives in `src/`. The rule fixtures and porting notes are the starting points for comparing behavior with upstream. [Source](https://github.com/yielded-dev/effect-tsrs) · [Porting notes](https://github.com/yielded-dev/effect-tsrs/blob/main/PORTING.md) · [Fixture guide](https://github.com/yielded-dev/effect-tsrs/blob/main/fixtures/all/HARNESS.md)

Install Node.js with npm, rustup, a C compiler and CMake. Use the toolchain and components pinned in `rust-toolchain.toml`. Run `./scripts/setup effect-tsrs` to install locked npm dependencies and prepare the pinned compiler checkout. `./scripts/check effect-tsrs` runs `npm run check` and `npm test` for formatting, Clippy and the Rust and Node tests. Rule parity, native-package and release verification have their own commands in the porting notes.
